# Phabricator commit-message integration

## Detect

Strong signals:

- `secure.phabricator.com`
- Task identifiers such as `T123`
- Differential revision identifiers such as `D123`
- Diffusion, Differential, or Maniphest terminology
- A custom self-hosted Phabricator domain

Phabricator is legacy software and local installations may have customized behavior.

## Neutral references

Prefer a neutral task reference when exact automation is unknown:

```text
fix(parser): handle empty heredoc marker

Refs: T123
```

A Differential revision may appear as a separate trailer according to local tooling:

```text
fix(parser): handle empty heredoc marker

Refs: T123
Differential-Revision: D456
```

Preserve the exact trailer form generated by Arcanist or required by the repository. Some installations historically use `Differential Revision:` rather than a strict Git-trailer token.

## Task closure

Phabricator installations can recognize forms such as `Fixes T123`, but upstream documentation is sparse and task-status prefixes can be reconfigured.

```text
fix(parser): handle empty heredoc marker

Fixes T123
```

Use a closure phrase only when local repository guidance confirms it. Otherwise use `Refs: T123`.
