# Divide by task groups, subdivide by tasks

When analyzing a goal, divide the request in as small as possible tasks and group them in sets.
Depending on the request, these sets should be bounded to an atomic boundary.

E.g.:
- Functional and research requests can be divided into tasks groups that represent as small as possible functional features and with as small as possible tasks under it
- Technical and implementation requests can be divided into tasks groups that represents as small as possible Git commits and with as small as possible tasks under it
