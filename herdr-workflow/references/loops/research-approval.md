# Research Approval Loop

Use this loop to get the Coordinator's findings about affected repositories and change impact approved before planning begins.

## Participants

- [Coordinator](../roles/coordinator.md): assigns research and obtains user approval.
- [Researcher](../roles/researcher.md): investigates the request and reports findings.
- User: approves the findings or requests clarification or changes.

## Steps

1. Coordinator sends the Researcher the original request and relevant context.
2. Researcher identifies affected repositories, likely change areas, side effects, constraints, and viable solutions, then returns findings to the Coordinator.
3. Coordinator presents the findings for user review.
4. If the user requests changes or clarification, Coordinator routes that feedback to the Researcher. Researcher updates the findings and returns them to the Coordinator; repeat from step 3.

## Completion

The loop passes when the user approves the research findings. Coordinator then gives the approved findings to the Speccer.
